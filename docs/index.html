Production-Grade Terabox Gateway

Direct downloads & HLS streaming, engineered for scale.

TeraBridge is an enterprise-ready async Python API service and CLI built on FastAPI, Uvicorn, and HTTPX. It dynamically bypasses session verification blocks, extracts high-speed direct download links, generates playable HLS manifests, and manages distributed multi-account failover.

Engineered Architecture

Production Capabilities

Async-First Core

Powered by FastAPI and Uvicorn ASGI loop with HTTPX connection pooling and HTTP/2 multiplexing. Zero OS thread exhaustion.

Native HLS Streaming

Rewrites m3u8 manifests with multi-bitrate profiles (1080p, 720p, 480p, 360p) for immediate playback in VLC, Apple Safari, and PotPlayer.

HMAC Token Signing

All download, stream manifest, and segment proxy URLs are signed with cryptographic SHA256 HMAC tokens with customizable TTL tiers.

Multi-Account Failover

Rotate between dozens of pooled Terabox accounts via Redis with continuous background health checks and automatic failover.

Single-Flight Collapsing

Concurrent burst requests targeting identical share links are deduplicated into a single upstream request, eliminating stampedes.

Egress Bandwidth Saver

Toggle REDIRECT_SEGMENTS=true to issue HTTP 307 redirects straight to upstream CDNs, slashing egress bandwidth by 90%.

Getting Started

Quick Start (30 Seconds)

Clone the repository, configure your Terabox session cookie, and launch the ASGI server locally:

Terminal / Bash
# 1. Clone repository & install dependencies git clone https://github.com/saahiyo-cloud/TeraBridge-api.git cd TeraBridge-api pip install -r requirements.txt # 2. Configure credentials in .env echo 'TERABOX_COOKIE="ndus=YOUR_NDUS_TOKEN; PANWEB=1"' >> .env echo 'API_KEY="my_secret_key"' >> .env # 3. Start high-performance Uvicorn server (port 5000) python api/index.py
Windows Performance Notice: Always bind and make requests against http://127.0.0.1:5000 rather than http://localhost:5000. On Windows systems, reverse DNS resolution of localhost adds ~2000ms latency to every request.

Security & Access Control

Authentication Strategy

When REQUIRE_API_KEY is enabled (default in production), protected endpoints accept credentials via four distinct channels:

Method Header / Format Best For
Custom Header X-API-Key: my_secret_key Standard backend-to-backend API integrations.
Bearer Token Authorization: Bearer <key_or_firebase_jwt> Supports both static API keys and Google Firebase Client ID tokens.
Query Parameter ?key=my_secret_key or ?api_key=my_secret_key Direct media player feeds (VLC, PotPlayer, Infuse, Kodi).
JSON Body { "key": "my_secret_key" } POST requests to /api/resolve or admin control endpoints.
Cryptographic Signing

HMAC-Signed Media URLs

To allow external video players and download managers to stream sub-resources without leaking your master API_KEY, all generated URLs include SHA256 HMAC signatures (sig + exp):

Resource Type Default Free TTL Premium Tier TTL Environment Variable
Stream Segments (.ts) 30 Minutes (1,800s) 2 Hours (7,200s) SIG_TTL_SEGMENT_FREE
Direct Downloads 2 Hours (7,200s) 24 Hours (86,400s) SIG_TTL_DOWNLOAD_FREE
HLS Manifests (.m3u8) 24 Hours (86,400s) 30 Days (2,592,000s) SIG_TTL_MANIFEST_FREE
Video Thumbnails 24 Hours (86,400s) 30 Days (2,592,000s) SIG_TTL_THUMBNAIL_FREE
Endpoint Reference
GET POST /api/resolve
API Key Required

Resolves a Terabox share link, bypasses captcha/token checks, and returns signed download URLs and HLS streaming manifests.

Query Parameters

Parameter Type Requirement Description
url string Required Full Terabox share URL (e.g. https://1024terabox.com/s/...). Also accepts link.
mode string Optional download (default), stream, or list. Aliased as action.
wait boolean Optional When true or 1, blocks and retries while video transcoding is pending. Default: false.

GET /api/stream/manifest
Signed or API Key

Aliases: /api/stream/playlist.m3u8. Returns an adaptive bitrate HLS manifest. Media segment paths within the manifest are rewritten to pass through TeraBridge's signed proxy.

Parameter Type Description
surl string Terabox share slug (e.g. 1Ay4FfmgooobETTVRHcf4mA) or full URL.
fs_id string Specific file ID inside the share. Optional if folder contains only 1 video.
quality string Target resolution: 1080p, 720p, 480p, 360p. Omit for adaptive master playlist.
GET /api/download
Signed or API Key

Proxies binary downloads directly from Terabox upstream storage. Supports Range requests (206 Partial Content) for resumable downloads and download managers.

GET /api/stream/segment
HMAC Signed

Aliases: /api/stream/segment.ts. Delivers video segments. When REDIRECT_SEGMENTS=true, issues an immediate HTTP 307 redirect directly to Baidu/Terabox CDN edge, saving container egress bandwidth.

GET /api/thumbnail
HMAC Signed

Proxies image thumbnails. Includes SSRF domain guards restricting upstream fetch to authorized *.terabox.com and *.baidupcs.com hosts.

GET /api/stats
Admin Only

Provides system telemetry: cache hit ratio, rate-limiter state, session token health status, and active account pool rotation.

GET POST /api/admin/config
Admin Only

Dynamically inspect or register new Terabox accounts into the Redis account pool without restarting or redeploying the service container.

GET POST /api/cron/validate
Cron Secret

Session keep-alive ping. Checks cookie validity against Terabox. If expired, automatically fails over to the next healthy account and dispatches an alert to NOTIFICATION_WEBHOOK_URL.

Configuration Reference

Environment Variables

Variable Default Description
TERABOX_COOKIE unset Primary credential. Full cookie string (must contain ndus=...; PANWEB=1).
API_KEY None Master secret key for securing API endpoints.
REQUIRE_API_KEY auto Set to 0 or false to disable auth during local debugging.
HMAC_SECRET API_KEY Secret for signing time-limited proxy URLs.
CACHE_TTL 60 Cache retention TTL in seconds for resolved link payloads.
RATE_LIMIT_RPM 30 Maximum requests per minute per IP address.
REDIRECT_SEGMENTS false Return HTTP 307 redirects to CDN for .ts segments. Cuts egress ~90%.
UPSTASH_REDIS_REST_URL unset Upstash Redis URL for distributed caching, rate-limiting, and account pools.
UPSTASH_REDIS_REST_TOKEN unset Upstash Redis authentication token.
NOTIFICATION_WEBHOOK_URL unset Discord or Slack incoming webhook for session expiration alerts.

Cloud Deployment

Deploy to Railway

Railway uses the repository's railway.toml and multi-stage Dockerfile automatically:

  1. Push this repository to your GitHub account.
  2. In Railway Dashboard: New Project → Deploy from GitHub repo.
  3. In the service Variables tab, set TERABOX_COOKIE, API_KEY, and REDIRECT_SEGMENTS=true.
  4. Railway auto-provisions the container and binds PORT automatically.

Deploy to Render.com

Render uses the included render.yaml Blueprint with free-tier tuning pre-configured:

  1. Navigate to Render Dashboard → New + → Blueprint.
  2. Connect your repository. Render automatically generates the service with a secure randomized API_KEY.
  3. In the Environment tab, populate TERABOX_COOKIE.

Deploy to Vercel (Serverless)

Vercel CLI
npm i -g vercel vercel --prod

Configure API_KEY and TERABOX_COOKIE in Project Settings → Environment Variables. Connect Upstash Redis for distributed cache persistence across serverless invocations.

Docker & Compose

Docker Commands
# Build and run container docker build -t terabridge-api . docker run -d -p 8000:8000 --env-file .env terabridge-api # Or run via docker-compose docker-compose up --build -d
